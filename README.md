# SalesCost Pro – Bản cập nhật xem thử

Bản web tĩnh quản lý chi phí, có thể mở trực tiếp hoặc triển khai lên Vercel.

## Cập nhật chính
- Đổi module “Chi phí bán hàng” thành “Chi phí”.
- Dashboard tách ngân sách năm và ngân sách tháng thành hai dòng.
- Mỗi dòng có: Ngân sách, Đã phê duyệt, Đã sử dụng, Còn lại, Chờ phê duyệt.
- Dữ liệu gốc không còn nút thêm ngân sách, khôi phục dữ liệu hoặc thao tác xóa chương trình.
- Giữ quy trình phê duyệt: Người tạo đơn → Trưởng bộ phận → Tài vụ.

## Chạy thử
Mở `index.html` trực tiếp trong trình duyệt.

## Vercel
- Framework Preset: Other
- Build Command: `npm run build`
- Output Directory: `dist`
